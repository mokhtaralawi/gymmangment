# النادي اليمني الصحي - نظام إدارة النادي الرياضي والشؤون المالية

منظومة متكاملة لإدارة الصالات الرياضية، المشتركين، الاشتراكات، الدوام بالبصمة، والشؤون المالية والمحاسبية.

**برمجة وتصميم:** يمن كود لتصميم الأنظمة والبرمجيات الحديثة

---

## 🚀 التشغيل السريع (Quick Start)

### 1. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```

### 2. تشغيل السيرفر المحلي
```bash
python run.py
```
سيعمل الخادم تلقائياً على الرابط:
👉 **http://127.0.0.1:5000**

## 🌟 الميزات والمواصفات
* **الهوية البصرية:** نمط الحماس الناري وكمال الأجسام عالي التباين (Titanium Fire).
* **الخط المعتمد:** خط Cairo العربي بجميع أوزانه.
* **الوضع الليلي والنهاري (Dark/Light Mode):** تبديل فوري وزر ذكي يحفظ الاختيار في المتصفح.
* **بطاقات المشتركين الرقمية:** بطاقة رياضية مزودة برمز QR ورابط مشاركة مباشر عبر WhatsApp.
* **النواة المحاسبية:** دليل شجري خماسي، سندات قبض وصرف، قيود يومية، ودفتر أستاذ عام.
* **إدارة المدربين والدوام:** استيراد حركات البصمة CSV، ومسير الرواتب الشهري مع الطباعة.
