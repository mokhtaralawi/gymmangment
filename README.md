# 🔥 النادي اليمني الصحي - نظام إدارة النادي الرياضي والشؤون المالية المتكامل

منظومة ويب متكاملة وحديثة لإدارة صالات كمال الأجسام، اللياقة البدنية، المشتركين، الاشتراكات، فترات التمرين، أنواع وطرق الدفع، الفواتير الحرارية، الدوام بالبصمة، والشؤون المالية والمحاسبية.

> **برمجة وتصميم:** **يمن كود لتصميم الأنظمة والبرمجيات الحديثة**  
> **حقوق الفواتير الحرارية:** **يمن كود للبرمجيات**  
> **دليل التوثيق الكامل:** للاطلاع على الدليل المفصل لكافة شاشات ووظائف النظام، راجع [ملف التوثيق الشامل (DOCUMENTATION.md)](DOCUMENTATION.md).

## 🚀 التشغيل السريع (Quick Start)

### 1. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```

### 2. تشغيل السيرفر المحلي
```bash
python run.py
```
سيعمل الخادم تلقائياً على الرابط:  
👉 **http://127.0.0.1:5000**

## 🌟 أبرز الميزات والمواصفات المعتمدة

1. **الهوية البصرية والحماس الناري (Titanium Fire):**
   * تصميم مستوحى من بطولات ورياضة كمال الأجسام والحديد.
   * اعتماد خط **Cairo** العربي المتناسق بجميع أوزانه.
   * دعم الوضعين الليلي والنهاري (Dark/Light Mode) مع تباين فائق وسواد فاحم للنصوص في الوضع النهاري.
2. **إدارة المشتركين والبطاقات الذكية:**
   * تسجيل المشترك وتاريخ البدء التلقائي (من اليوم أو تاريخ مخصص).
   * بطاقة عضوية رقمية فاخرة مزودة برمز QR ورابط مشاركة فوري عبر WhatsApp.
3. **فترات التمرين اليومية (Daily Shifts):**
   * تنظيم أوقات الصالة (فترة صباحية، بعد العصر، مسائية).
   * ربط كل فترة بكابتن/مشرف مسؤول وتعيين الفترة للاعب عند الاشتراك.
4. **أنواع وطرق الدفع المتعددة (Payment Methods):**
   * دعم كامل لوسائل الدفع: كاش (نقداً)، محفظة الكريمي (Kurimi Pay)، محفظة جيب (Jeep)، ون كاش (OneCash)، جوالي، وحوالات بنكية.
   * ربط كل وسيلة بحسابها المالي في شجرة الحسابات، مع إحصائيات تحصيل لحظية.
5. **الدفع الجزئي وتسجيل الديون وسدادها:**
   * إمكانية دفع جزء من المبلغ وتسجيل المتبقي كدين بذمة المشترك.
   * تنبيهات ديون بارزة، وزر سداد المتبقي على دفعات مع توليد سندات قبض آلية.
6. **نظام الفواتير الحرارية المزدوجة (POS 80mm):**
   * طباعة حرارية فورية وتلقائية عند إنشاء مشترك أو اشتراك.
   * طباعة نسختين في أمر واحد مع فاصل قص:
     * **نسخة المشترك (العضوية)**
     * **نسخة الإدارة (للمطابقة والأرشيف)**
   * تذييل رسمي بحقوق: **«يمن كود للبرمجيات»**.
7. **بوابة الحضور السريع:**
   * تسجيل دخول اللاعبين بمسح الكود أو الرقم مع فحص آني لصلاحية الاشتراك.
8. **شؤون الموظفين والدوام والرواتب:**
   * دوام البصمة مع استيراد ملفات CSV، وإعداد مسير الرواتب والطباعة.
9. **نظام مالي ومحاسبي متكامل:**
   * شجرة حسابات خماسية، سندات قبض وصرف، قيود يومية مزدوجة، ودفتر أستاذ عام.
10. **الأمان والرقابة والنسخ الاحتياطي:**
    * سجل تدقيق رقابي شامل، ونسخ احتياطي واسترجاع لقاعدة البيانات بنقرة واحدة.
11. **التقارير الدورية الشاملة (يومية · أسبوعية · شهرية):**
    * تقارير تحليلية ومؤشرات مالية دقيقة للإيرادات، المصروفات، صافي الأرباح، والديون.
    * توزيع المبيعات حسب وسيلة الدفع وباقات الاشتراك وفترات التمرين مع إمكانية الطباعة.
12. **الموازنة اليومية ومطابقة الصندوق (الدخل والخرج):**
    * حساب الدخل مقابل الخرج اللحظي، ومطابقة النقدية في الدرج مع الرصيد الدفتري لكشف أي عجز أو زيادة.
    * طباعة إيصال موازنة حراري (80mm) أو تقرير رسمي (A4) للاعتماد والتوقيع.
13. **دعم تطبيقات الويب التقدمية (PWA):**
    * ملف بيان Manifest وأيقونات عالية الدقة، مع عامل خدمة Service Worker لدعم العمل دون اتصال.
    * زر تثبيت التطبيق بضغطة واحدة على الهواتف وأجهزة الكمبيوتر كتطبيق مستقل.
