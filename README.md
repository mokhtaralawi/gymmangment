# نادي - نظام إدارة النادي الرياضي والشؤون المالية (نسخة التطوير المحلية)

نظام متكامل ومستنسخ بالكامل لإدارة الأندية والصالات الرياضية والمشتركين والاشتراكات والدوام والشؤون المالية والمحاسبية.

---

## 🚀 التشغيل السريع (Quick Start)

### 1. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```

### 2. تشغيل السيرفر المحلي
```bash
python run.py
```
سيعمل الخادم تلقائياً على الرابط:
👉 **http://127.0.0.1:5000**

## 📁 الهيكل البرمجي للمشروع
```text
gym/
├── app/
│   ├── __init__.py           # تهيئة التطبيق وبذر البيانات الأولية
│   ├── models.py             # نماذج قاعدة البيانات (SQLAlchemy)
│   ├── utils.py              # أدوات المساعدة وسجل التدقيق (Audit)
│   ├── routes/               # المسارات والموديولات البرمجية
│   │   ├── auth.py           # المصادقة والمستخدمين والملف الشخصي
│   │   ├── dashboard.py      # لوحة التحكم والمؤشرات الحيوية
│   │   ├── members.py        # إدارة المشتركين والملفات
│   │   ├── subscriptions.py  # الاشتراكات والباقات
│   │   ├── attendance.py     # حضور وزيارات المشتركين
│   │   ├── employees.py      # شؤون الموظفين والدوام ومسير الرواتب
│   │   ├── accounting.py     # السندات وشجرة الحسابات واليومية ودفتر الأستاذ
│   │   ├── notifications.py  # مركز الإشعارات وقواعد الاستحقاق
│   │   └── system.py         # سجل التدقيق والنسخ الاحتياطي
│   ├── static/               # التصاميم الأصلية (CSS, JS, SVG Sprites, Icons)
│   └── templates/            # قوالب Jinja2 التفاعلية
├── backups/                  # مجلد النسخ الاحتياطية المولدة
├── config.py                 # إعدادات النظام وقاعدة البيانات
├── requirements.txt          # مكتبات بايثون المطلوبة
└── run.py                    # نقطة تشغيل السيرفر
```

## 🌟 الوحدات البرمجية المكتملة
1. **لوحة التحكم (Dashboard):** مؤشرات فورية لأعداد المشتركين، الاشتراكات الفعالة، الإيرادات والمصروفات، واختصارات سريعة.
2. **المشتركون (Members):** إضافة، تعديل، بحث، أكواد فريدة لكل مشترك، ملخص الاشتراكات والزيارات.
3. **الاشتراكات والباقات (Subscriptions & Plans):** باقات يومية، أسبوعية، وشهرية، احتساب تلقائي للمدة، وإمكانية إلغاء الاشتراك مع السبب.
4. **حضور المشتركين (Member Attendance):** تسجيل دخول لحظي والتحقق من سريان الاشتراك مع منع التكرار.
5. **الموظفون والدوام (Employees):** ربط أجهزة البصمة، تسجيل الحضور والانصراف، و**استيراد ملفات CSV من جهاز البصمة**.
6. **مسير الرواتب (Payroll):** احتساب شهري للراتب الأساسي، المكافآت، الخصومات، أقساط السلف، وصافي الراتب مع إمكانية الطباعة.
7. **المحاسبة والمالية (Accounting Core):**
   * سندات القبض والصرف.
   * دليل الحسابات الشجري الخماسي القياسي.
   * القيود اليومية المحاسبية المزدوجة.
   * كشف حساب تفصيلي في دفتر الأستاذ.
8. **الأمان والنظام (Security & System):**
   * حماية ضد CSRF.
   * سجل تدقيق ورصد لجميع العمليات مع الـ IP.
   * إنشاء وتحميل نسخ احتياطية لقاعدة البيانات بضغطة زر.
